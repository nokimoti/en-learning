I

Five Rules to Survive

Principles

  1. 毎日、同じ時間にやる

    意志力に頼らない。朝食後・通勤前・寝る前など、既にある習慣の直後に貼り付ける(habit stacking)。「やるかどうか」を毎日考えないことが続く秘訣。

  2. 記録をつける、ただし簡素に

    ノートに「○月○日 / 多読○分 / ○語」程度で十分。可視化されると、サボった日も含めて全体が見える。各 Phase ページのトラッカーを使ってもよい。

  3. キリの悪いところで止める

    章末や段落末でなく、文の途中で時間が来たら止める。続きが気になる状態で終えると、翌日戻りやすい。ヘミングウェイの執筆術と同じ原理。

  4. サボった日は無かったことにする

    1日抜けてもプランは壊れない。「3日サボったからもう駄目だ」が一番危ない。翌日普通に再開する。完璧主義は学習の最大の敵。

  5. 順番を守る

    Phase I を飛ばして II に行かない。II を飛ばして III に行かない。土台が無いまま難しい教材に挑むと、辞書地獄に陥り萎える。順番を守るほうが結果的に速い。

II

Frequently Asked

FAQ
どうしても Phase I が退屈で耐えられません。
それは正常な反応です。Phase I は地味だし、興味ある哲学に触れられないストレスがある。ただし「退屈だから飛ばす」を選ぶと、結局 SEP の前で詰まって戻ってくることになる。妥協案として、週末の Aeon を週2回に増やしてもよい。それ以外は淡々と続ける。
仕事や学業で1週間まったく時間が取れませんでした。
プランは壊れていません。翌週から普通に再開してください。「取り戻そうとして無理する」のが一番続かない原因です。1〜2週間の中断は誰にでも起きます。「Phase I は3ヶ月」という見積もりに、こうした空白期間は最初から含まれていると思ってください。
教材が合いません。変えてもいいですか?
同じカテゴリ内で(多読は多読、語彙は語彙)変えるのは構いません。ただし「合わないから3冊目に変える」を繰り返すと、どの教材も終えられず学習効果が出ません。合わなくても最低2週間は使ってから判断してください。最初の数日の違和感は単に慣れていないだけのことが多い。
Exit Criteria を満たしていない気がします。1ヶ月延長するべき?
はい、延長してください。これは恥ずかしいことではなく、戦略的判断です。土台が薄いまま次に進むと、その先で必ず詰まって、結局戻ってくることになる。延長中は同じルーティンを続けるだけで OK。週末に Phase 1.5 / 2.5 として、少し難度を上げた読み物を試してもよい。
音読・リスニングはやらなくていいの?
このプランは「読解」に最適化されています。リスニングは別途必要なら追加可能ですが、まず読解を固めるのが優先。音読は語彙学習の中で例文音読する形で組み込まれています。議論への参加を真剣に考えるなら Phase III で哲学系 Podcast を加えるのがよいです(Philosophy Bites など)。
英作文の添削、誰にしてもらえばいい?
Phase III で英語アウトプットを始める時、添削先の選択肢:(1) Grammarly / DeepL Write などの AI ツール、無料の範囲で十分。(2) Claude などの LLM に「以下を分析哲学の英語として添削して」と頼む。(3) italki や Cambly でネイティブ講師に。(4) 大学院生レベルの友人がいれば直接。最初は (1)(2) で十分。(3)(4) は議論練習も兼ねられて理想的。
直観はいつ鍛えればいいの?
明示的に「鍛える」必要はありません。Phase II〜III で大量に哲学英語を読むうち、自然に芽生えてきます。もし Phase III 後半で意識的に磨きたくなったら、ミニマルペアを集めた書籍(Huddleston & Pullum の A Student's Introduction to English Grammar など)が使えますが、それは1年プランの外の話です。
挫折しそうです。どうしたらいいですか?
まず、ここまで続けてきた事実を認めてください。次に、「全部やる」を一旦やめる。Phase I なら多読30分だけでも続ける。語彙と構文は一旦休んでよい。毎日5分でも英語に触れることが、完全にやめないための最低ライン。3日で戻れます。それでも無理なら、1週間完全に離れる。罪悪感を持たない。
Phase の途中で Claude にまた相談していい?
いつでもどうぞ。教材の調整・スタックしている箇所・モチベの維持など、具体的に教えてくれれば対応します。Phase 移行時には進捗を報告してくれれば、次フェーズの細部を調整できます。
III

If You Are Stuck

処方箋
困った時のフローチャート

つまずいた時、まず自分の状態を以下のどれかに分類してください。原因が違えば処方箋も違います。

  1. 「時間が取れない」型

    → 60分を30分に減らしてよい。多読20分+語彙10分でも続けば勝ち。ゼロにしないことが唯一のルール。

  2. 「教材が退屈」型

    → 同カテゴリ内で別教材に。ただし2週間は使ってから判断。多読なら興味あるジャンルに寄せてよい(SF、伝記、エッセイなど)。

  3. 「進歩が見えない」型

    → 1ヶ月前の自分の記録を見返す。読書語数、引いた語数、所要時間。必ず変化がある。可視化ツールを導入してもよい(読書語数を週次でグラフ化)。

  4. 「萎える」型

    → 1週間完全に離れる。罪悪感を持たない。離れた後の「読みたい」が戻ってくる感覚を信じる。戻れない場合はそもそも目標を見直す時期かもしれない。

  5. 「教材が難しすぎる」型

    → Phase を1段下げる。Phase II が難しいなら Phase I を延長、Phase III が無理なら Phase II をもう1ヶ月。プライドより継続。
